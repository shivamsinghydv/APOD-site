# APOD new-tab site

### A simple new-tab site that displays the astronomy picture of the day from NASA's APOD API.
### built with HTML, CSS, and JavaScript (vite).

![preview of the site](/src/assets/preview.png)

[Try it live] (https://shivamsinghydv.github.io/APOD-site/)

## Quick Start
### Just add the link to your browser's new tab page settings.

### To view and edit locally, follow these steps:

## Pre-requisites
- NodeJS
- NASA API key

```bash
git clone https://github.com/shivamsinghydv/APOD-site.git
cd APOD-site
npm run dev
```

## Features
- Displays the astronomy picture of the day from NASA's APOD API.
- Shows the title of the picture.
- Responsive design for different screen sizes.
- Date picker to view pictures from different dates.
- search enginer switcher.
- shortcuts to popular websites with one-click add/remove.

## Under the hood
- It pings the NASA APOD API to fetch the astronomy picture of the day.
- Displays the picture, title, and date on the new tab page.
- Redirects to respective seach engine for search queries.
